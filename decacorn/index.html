데카콘 (Decacorn) 지원

데카콘은 Safari에서 광고와 추적기를 막는 앱입니다.

처음 설정하기 (Mac)

  1. 데카콘을 실행하고 "Safari 확장 설정 열기"를 누릅니다.
  2. Safari › 설정 › 확장 프로그램에서 데카콘 확장 7개를 모두 켭니다.
  3. "Decacorn" 웹 확장은 모든 웹사이트에서 항상 허용으로 설정해야 요소 숨김과 유튜브 광고 처리가 동작합니다.
  4. 앱으로 돌아오면 목록이 모두 초록색으로 바뀝니다. 첫 필터 변환에는 1분 정도 걸립니다.

자주 묻는 질문

특정 사이트가 깨져요. Safari 툴바의 데카콘 버튼을 눌러 그 사이트에서만 차단을 끌 수 있습니다.

결제는 어떻게 되나요? 설치 후 7일 동안 무료로 모든 기능을 쓸 수 있고, 이후에는 한 번만 결제하는 평생 이용권이 필요합니다. 같은 Apple 계정이면 "구매 복원"으로 다시 받을 수 있습니다.

Decacorn Support

Decacorn blocks ads and trackers in Safari.

Getting started (Mac)

  1. Open Decacorn and click "Open Safari Extension Settings".
  2. In Safari › Settings › Extensions, turn on all seven Decacorn extensions.
  3. Set the "Decacorn" web extension to Always Allow on Every Website so element hiding and video-ad handling work.
  4. Back in the app, every item turns green. The first filter compile takes about a minute.

FAQ

A site looks broken. Click the Decacorn button in the Safari toolbar to pause blocking on that site only.

How does pricing work? All features are free for 7 days after install. After that a one-time lifetime license is required. Use "Restore Purchases" with the same Apple Account to get it back.
